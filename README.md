## SQL E-Commerce Analysis Project (PostgreSQL)

Project Overview
This project focuses on analyzing e-commerce sales data using **PostgreSQL**.  
The goal is to extract meaningful business insights by applying **SQL concepts such as joins, aggregations, subqueries, and window functions**.

This project is designed as a **SQL portfolio project** for data analyst roles.

---

## Objectives
- Analyze customer purchasing behavior
- Identify top-selling products and categories
- Measure customer value and repeat purchases
- Track monthly sales trends
- Apply advanced SQL queries for business decision-making

---

## Dataset Description
 
   The project uses four datasets:

- **customers** – customer details and signup information  
- **products** – product details and categories  
- **orders** – order-level transaction data  
- **order_items** – item-level sales data  

All datasets are stored in CSV format and imported into PostgreSQL.

---

## SQL Analysis Performed
- Customer-wise total spending
- Category-wise total revenue
- Most expensive and best-selling products
- Month-wise sales analysis
- Product ranking using window functions
- Running total of monthly sales
- Percentage contribution of each category

---

## Key Business Insights
- Electronics category generates the highest revenue
- A small group of customers contributes most of the sales
- Laptop is the top-selling product
- Repeat customers are more valuable than one-time buyers
- Monthly sales show a consistent growth trend
